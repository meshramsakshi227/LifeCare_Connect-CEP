# LifeCare_Connect-CEP
LifeCare Connect – Healthcare Appointment Management System

Project Overview
LifeCare Connect is a web-based healthcare management application designed to simplify patient authentication and doctor appointment scheduling while providing a secure and user-friendly experience.

Key Features
- Secure Login System: Protects user accounts by temporarily locking them after three consecutive failed login attempts.
- Automatic Account Unlock: Displays a countdown timer indicating when users can try logging in again.
- Appointment Management: Enables patients to book and manage doctor appointments conveniently.
- Database Management: Uses MySQL to store and organize user, doctor, and appointment information.
- Responsive Interface: Provides an accessible and user-friendly design across different screen sizes.

Technologies Used
- Frontend: HTML5, CSS3
- Programming: JavaScript
- Database: MySQL

Project Files
- "index.html" – Main application interface
- "style.css" – Website styling and layout
- "script.js" – Login validation, account lockout, countdown timer, and related functionality
- "LifeCare_database.sql" – Database structure for storing application data

Project Objective
The main objective of LifeCare Connect is to make healthcare appointment scheduling easier while improving login security and organizing patient-related information efficiently.

Future Enhancements

- Online appointment notifications
- Doctor availability management
- Improved patient dashboard
- Additional authentication and security features
